# Evidence ledger

Every protocol and streaming fact the implementation relies on. Format:
`L-### | statement | class | source | firmware | confidence | notes`.

- **class**: `observed` (hardware test or capture), `derived` (REA static
  evidence), `inferred` (reasoning from derived facts) or `unknown`.
- **source**: REA Evidence ID (`ev_…`, from the session bundle exported to
  `~/dev/goxlr-re/evidence/`, never committed), a capture or hardware log, a
  `goxlr-utility@<commit>:path:line` reference or a USB-IF spec section.
- **firmware**: the device firmware the fact applies to; `n/a` for host-side
  facts, `?` while unknown.

## Conflicts and how to resolve them (Phase 3a)

the Phase 2 hardware observations disagree, or where SPEC.md must choose
between them. Each is resolved on hardware with **read-only checks first**
(PROMPT.md Phase 3a). Writes wait for Phase 5. The "Spec choice" column is
what [SPEC.md](SPEC.md) does until the conflict is resolved.
